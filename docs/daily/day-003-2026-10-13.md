## Problems and learnings

- **The OpenTelemetry distro defaults to gRPC.** Only the HTTP exporter is installed, so `OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf` is required. Read in the installed `opentelemetry/distro/__init__.py`.
- **The SDK's log switch is deprecated** (`OTEL_PYTHON_LOGGING_AUTO_INSTRUMENTATION_ENABLED`, SDK 1.45). The replacement, `opentelemetry-instrumentation-logging`, installs the OTLP log handler by itself. With `OTEL_PYTHON_LOG_CORRELATION=true` it first calls `basicConfig()` (root logger at INFO, stderr line with `trace_id=…`), then adds the OTLP handler, so each log line is in `docker logs` and in Loki with its trace id.
- **Starlette 1.8 deprecated `httpx` for `TestClient`**; it imports `httpx2` (pydantic org, 2.13.1 from 23 Sep) first. Switched.
- **uv installs a workspace member only when the root asks for it.** A plain `uv sync` is exact: it removes what the root doesn't list. Listing each service in the root `dev` group keeps `uv sync`, `uv run` and pre-commit's mypy working on a fresh clone.
- **ruff sorted `hello_fastapi` as third-party** until `src = [".", "platform", "services/*/src"]`.
- **`PathPrefix` compares strings, not path segments.** `PathPrefix(`/fastapi`)` caught `/fastapiX/hello`. A route for `/api/user` would catch `/api/users-admin` the same way. End prefixes with `/`.
- **Tell 404s apart by body:** Traefik's is `404 page not found` (no route matched); FastAPI's is `{"detail":"Not Found"}` (route matched, path unknown to the service).
- **`aliasHeadersStrategy`:** WSGI servers map `X_Auth_User` and `X-Auth-User` to the same `HTTP_X_AUTH_USER`, so a client could spoof a header the gateway sets. Set to `delete` on `web`. Traefik also warns about encoded characters in paths (`%2F` and others are allowed by default); decide in Phase 1, when real routes and auth exist.
- **Traefik trusts any incoming `traceparent`.** `trace-check` depends on it. On a public edge a client could choose trace ids and force sampling (`-01`) on every request: telemetry cost under the client's control. Recorded in ADR-0004 for Phase 5.
- **Tempo's v2 trace API answers 200 with `{"trace":{}}`** when the trace isn't there (yet); the v1 API answers 404. A check must look at the body, not the status.
- **Healthchecks would flood Tempo:** every 10 s, forever. `OTEL_PYTHON_FASTAPI_EXCLUDED_URLS=healthz` keeps them out (checked: 0 `/healthz` spans).
- **Zero-code keeps two ASGI `http send` spans** per request; hiding them needs `exclude_spans` in code. Accepted.
- **Memory under swap:** a later sample showed Traefik 10 MiB and hello-fastapi 14 MiB of `anon`, because the kernel had swapped idle pages out (swap 3.4 → 4.9 GiB). `anon` + `memory.swap.current` gave 23 / 51 MiB again, the same as the first sample. Use that sum when the laptop swaps.
- **lgtm reached 972 MiB of its 1 GiB limit** after the day's traces (507 MiB process memory; Day 2: ~330). File cache is freed before anything is killed, but process memory grows with stored data. Watch it on Days 4–5.

## Decisions

- Service skeleton, zero-code tracing, how services run, and Traefik with the file provider: [ADR-0004](../adr/0004-service-skeleton-and-gateway.md).
- Services publish no ports; Traefik is the only way in.

- Instrumentation packages are locked dependencies, never `opentelemetry-bootstrap`.
- Kong not chosen: heavier, and k3s (Phase 5) ships Traefik. JWT at the edge will need `ForwardAuth` to Identity (the JWT middleware is Traefik Hub only); decide in Phase 1.
